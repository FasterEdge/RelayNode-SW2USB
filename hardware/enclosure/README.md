# RelayNode-SW2USB 外壳

3D 打印外壳，覆盖 `sw2usb_main` PCB（39.4 × 14.2 mm）。

> 来源：嘉立创 EDA 工程 `sw2usb_main.eprj2` 实测板框（1550 × 560 mil）。
> 风格：方形盒式上下盖，USB-C 从短边出线，8 个接线端子从顶板穿出。

## 目录结构

```
enclosure/
├── blender/                  # Blender 源文件

```

## 几何参数

### 整体

| 维度 | 数值 |
|---|---|
| 外尺寸 | 45.4 × 20.2 × 11.6 mm |
| 壁厚 | 2.0 mm |
| 板下间隙 | 1.4 mm |
| 板上空间（内腔高度） | 4.6 mm |

### 上盖（`top.stl`）

- 顶部 **8 个端子方孔**（1.6 × 1.6 mm，2.54 mm 间距），两排
  - SW 排：J2–J5（y ≈ −6.86）
  - GND 排：J6–J9（y ≈ +7.11）
- 短边 **USB-C 通孔**：14.0 × 4.6 mm（y 范围 −7.0 至 +7.0 覆盖板 y 短边 99%，z 范围 0.8 至 5.4 贯穿短边壁厚），底部边缘对齐分模面
  - 短边壁只保留顶部 2 mm（z 5.4–7.4）作结构件，让 Type-C 头从底部露出 4.6 mm
  - 短边壁 y 端柱（y 端各 1.6 mm）保持完整宽度，结构强度充足
- **4 处卡扣凸耳**：+Y/−Y 外壁 z 0.4–0.7 局部外凸 0.4 mm

### 底座（`bottom.stl`）

- 开口朝上，PCB 嵌入槽 41.4 × 16.2 × 3.0 mm
- **4 处滑动凹槽**：+Y/−Y 外壁 z 0.4–0.8 局部内凹 0.4 mm，与上盖凸耳配合

### 卡扣原理

滑动卡扣（snap-fit）：上盖从顶部压下，凸耳沿凹槽斜面滑入，靠材料弹性 + 0.4 mm 过盈摩擦固定。
无需螺丝、无需胶水，可重复拆装。

> **建议**：如果打印后扣合困难，可将凹槽/凸耳处的 Z 范围微调 ±0.1 mm，或在切片器中设置 X/Y 水平补偿 +0.05 mm。

## 打印参数建议

| 参数 | 数值 |
|---|---|
| 材料 | PLA / PETG |
| 层高 | 0.2 mm |
| 壁（Wall） | ≥ 2 条（0.4 mm 喷嘴）或 4 条（0.8 mm） |
| 填充（Infill） | 20 % |
| 顶/底层（Top/Bottom） | ≥ 4 层 |
| 支撑 | 仅外壳打印**不需要**支撑（已验证无悬垂面） |
| 打印方向 | 上盖**顶面朝上**，底座**顶面（开口）朝上** |
| 水平扩展（Horizontal Expansion） | −0.05 mm（凹槽配合更顺滑） |

## 关键设计验证

| 检查项 | 结果 |
|---|---|
| 上下盖 mesh 水密（非流形/边界） | ✅ 0 / 0 |
| 顶板 8 个端子方孔位置 | ✅ 对准 J2–J9 |

## 嘉立创 EDA 协作工作流

外壳尺寸由嘉立创 EDA 实时读取，所有元件位置通过 JLC→Blender 坐标映射：

```
Blender x = (jL_x_mil − 725) × 0.0254
Blender y = −(jL_y_mil + 620) × 0.0254
Blender z = 0.8 + ½ × 元件高度（板上表面参考）
```

板中心对齐原点（0, 0, 0），X 轴为板长方向（39.4 mm），USB 短边朝 −X。

如需从 EDA 重新同步 PCB 元件位置，编辑 `enclosure.blend` 中 `PCB_Reference` 集合的子对象尺寸/位置即可。
